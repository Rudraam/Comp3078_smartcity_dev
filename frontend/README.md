# Smart City Explorer - Frontend

React 18 + TypeScript + Vite frontend application.

## Setup

```bash
npm install
npm run dev
```

## Development

- Dev server runs on `http://localhost:5173`
- API calls proxy to backend at `http://localhost:8000`

## Build

```bash
npm run build
```

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui components
- TanStack Query
